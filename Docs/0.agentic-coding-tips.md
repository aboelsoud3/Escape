Do **not** use the AI as a "code generator."

use it as an **AI Software Team**.

This is the philosophy behind Agentic Coding.

Instead of:

```
Human
   ↓
Ask AI
   ↓
Receive Code
```

The workflow becomes:

```
Human (Creative Director)

        ↓

AI Project Manager

        ↓

AI Solution Architect

        ↓

AI Technical Lead

        ↓

AI Engine Programmer

        ↓

AI Gameplay Programmer

        ↓

AI QA

        ↓

Human Review

        ↓

Git Commit
```

That is how I'd build **PULSE**.

---

# The Golden Rule

The AI should **never** receive the whole project.

Instead, every task should be:

* Small
* Measurable
* Reviewable
* Testable

Think of each prompt as a GitHub issue.

---

# Phase 0 — Bootstrap the AI Team

Instead of immediately asking OpenCode:

> Build my game.

Start by giving it a project identity.

```
You are part of the PULSE development team.

Your role:
Senior Gameplay Engineer.

Constraints:

- 1.44 MB executable target
- C++20
- raylib
- OpenGL 3.3
- No external assets unless approved
- Everything procedural whenever possible
- Never increase complexity unnecessarily.
- Prefer deterministic algorithms.
- Never modify unrelated files.
- Produce clean, documented code.
```

This becomes the **System Prompt**.

# If I were leading this project with OpenCode

I would actually introduce one more layer that most agentic workflows lack: a **Project Constitution**.

This is a single document (for example, `docs/CONSTITUTION.md`) that every agent reads before making changes. It contains the project's non-negotiable principles, such as:

1. **Gameplay over graphics.**
2. **Determinism over convenience.**
3. **Procedural generation over stored assets.**
4. **Maintain 60+ FPS on mid-range hardware.**
5. **Every feature must strengthen the "one more run" loop.**
6. **Every added kilobyte must justify its existence.**
7. **No feature is complete without tests and documentation.**

Whenever an AI proposes a solution, it should first evaluate it against the Constitution. If a proposed feature violates one of those principles—for example,
by adding a large texture pack instead of generating a material procedurally—the agent should reject its own solution and propose one that aligns with the project's vision.

That's the closest I've found to making an AI coding assistant behave like a disciplined senior engineer instead of a code autocomplete tool.
