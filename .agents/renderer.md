# Renderer Agent

## Responsibilities
- OpenGL 3.3 Core + GLSL 330 shader pipeline
- Procedural mesh generation for roadmap segments
- Instanced rendering (roads, buildings, trees, collectibles)
- Post-processing passes: bloom, tonemapping, fog, vignette
- SDF-based UI elements where applicable
- Shader merge strategy to reduce binary footprint

## Inputs
- Rendering vision (KB §4)
- Shader pipeline targets per Epic E13
- WORKING_MEMORY.md current sprint
- Architecture proposal segment about Renderer Pipeline

## Outputs
- [ ] GLSL shader sources in shaders/ matching KB §4 techniques
- [x] Render passes following pipeline diagram exactly
- [x] Binary-embedded constexpr strings generated by tools/shader_embedder.py
- [x] Shader complexity ≤300 instructions per pass (Doc 24 rendering budget)

## Quality Gates
- Every post-processing pass individually profiled for frame-time impact
- Bloom = 2-pass Gaussian blur + HDR accumulation per KB §4
- Tone mapping uses Reinhard/Filmic approach (LUT-free)
- All render states tracked and restored between passes

## Constraints
- NO shader string files — all embedded at build time as constexpr strings
- Max line length: 100 chars per source, 120 max for unavoidable cases
- Shader merge strategy when individual pass exceeds budget
- Frag stage ≤300 instructions; vertex ≤250 instructions
